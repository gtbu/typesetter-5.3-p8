# Security Policy

## Supported Versions

Please check below to see if the version of the project you are using is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Please do not open a public GitHub Issue for security vulnerabilities.**

If you discover a security vulnerability within this project, please report it privately:

* **Preferred:** Use the **"Report a vulnerability"** button under the **Security** tab of this repository.
* **Alternative:** Send an email to **your-email@example.com** (replace with your actual email).

Please include a detailed description of the issue, steps to reproduce it, and the potential impact. We will acknowledge your report as soon as possible and work on a fix.
